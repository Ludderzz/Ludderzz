#### 🎮 Minecraft KillCam Plugin
**A Call of Duty-style killcam for Minecraft multiplayer servers.**

An advanced custom Minecraft plugin built to capture and replay recent player kills in real-time. Designed to bring seamless competitive mechanics to PvP servers.

* **Core Features:**
  * **Packet Interception & Recording:** Captures precise player movements and combat interactions using NMS packets.
  * **NPC Rendering:** Spawns custom ReplayNPC instances to accurately mimic and replay the final moments leading up to an elimination.
  * **Seamless Performance:** Engineered for high-intensity 1.8.9 PvP environments without adding server latency.

* **Tech Stack:** Java, Spigot/Bukkit API, NMS (Net Minecraft Server) Packets, Custom NPC Handling.
